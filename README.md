# Security
# Objetivo
El objetivo del proyecto es crear una aplicación móvil de seguridad personal que permita a los usuarios avisar a sus contactos de confianza cuando se sienten en peligro, compartiendo su ubicación de forma rápida y discreta. Para que pedir ayuda no consuma tiempo en un momento crítico, las funciones principales estarán disponibles desde un widget en la pantalla de inicio del dispositivo. De manera secundaria, la app permitirá abrir el marcador del dispositivo móvil con el número de emergencia ya escrito, sin realizar la llamada de forma automática, de modo que el usuario decide si la confima.
